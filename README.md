#Campus Lost and Found App

##Overview

Campus Lost and Found is an Android mobile application designed to help
students and members of the university community report lost items,
report found items, and locate belongings reported by other users.

The application provides a centralized platform for managing lost and
found items, making it easier for people to reconnect with their missing
belongings within the campus community.

##Features

-   Home Screen: Provides navigation to the main application features.
-   Report Lost Items: Allows users to submit details about belongings
    they have lost.
-   Report Found Items: Allows users to report items they have found.
-   View Reported Items: Displays submitted lost and found reports.
-   Search Functionality: Allows users to search for reported items by
    name.
-   Filter Functionality: Enables filtering by item category and status
    (Lost or Found).
-   Claimed Items: Allows items to be marked as claimed.
-   User Interface: Features a structured and user-friendly interface
    with appropriate colours, icons, spacing, and layouts.

###Technologies Used

##Project Structure

Component: Home Screen Main Files: MainActivity.java, activity_main.xml

Component: Report Form Main Files: ReportActivity.java,
activity_report.xml

Component: View Items Main Files: ItemAdapter.java, item_row.xml,
activity_view_items.xml

Component: Search, Filter and Claimed Items Main Files:
ViewItemsActivity.java

Component: UI, Colours and Icons Main Files: app_values.xml

##Installation and Setup

Follow these steps to run the application locally:

1.  Clone the repository:

    git clone https://github.com/LeonKandie456/Campus-Lost-And-Found.git

2.  Open Android Studio.

3.  Select Open and navigate to the cloned project folder.

4.  Allow Gradle to sync and download the required dependencies.

5.  Run the application using an Android emulator or a connected Android
    device.
